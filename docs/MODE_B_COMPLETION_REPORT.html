Executive Summary & Research Contribution

Core Principle

Generate only what is structurally justified by the observed scene, and clearly distinguish observed geometry from inferred/generated geometry. If evidence is insufficient, leave the region unresolved rather than hallucinating geometry.

PLANE VUE introduces Visibility-Aware Constraint Completion for static room walkthrough videos. Instead of applying speculative unconstrained generative AI, the system couples a Structure-from-Motion (SfM) reconstruction pipeline with rigorous 3D voxel coverage raycasting, cardinal perimeter occlusion detection, architectural constraint evaluation, and non-overwrite geometry validation.

Provenance System

Status Color Code Definition Scientific Evidence Required
OBSERVED Emerald Green Directly observed 3D surfaces Multi-view triangulated points, intersecting camera ray frustums.
INFERRED Royal Blue Structurally supported geometry Collinear extension of observed wall, orthogonal symmetry pairing.
GENERATED Purple Room-shell perimeter closure Room envelope bounding box closure anchored by floor and walls.
CORRECTED Amber Trimmed / reconciled geometry Synthesized geometry trimmed to prevent overwriting observed data.
