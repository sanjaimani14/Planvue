PLANE VUE

“See the space. Reconstruct the unseen.”

HNX26EPS06 — 3D Scene Generation from Blueprints and Room Video

1. Executive Summary

PLANE VUE is an AI-assisted and geometry-grounded 3D spatial reconstruction platform designed to transform 2D architectural blueprints and handheld room walkthrough videos into metric 3D BIM scenes. Unlike conventional approaches that either fail to complete unseen regions or hallucinate non-existent features, PLANE VUE introduces Visibility-Aware Structural Constraint Completion with a 4-tier Provenance Contract (OBSERVED, INFERRED, GENERATED, CORRECTED).

2. Dual-Mode Architecture

MODE A: Blueprint → 3D BIM

Morphological line analysis, door/window symbol extraction, room polygon inference, metric scale calibration, and solid mesh extrusion.

MODE B: Room Video → 3D + Completion

Keyframe extraction, 6-DOF camera trajectory estimation, visibility ray casting, unobserved region detection, and conservative Manhattan structural completion.

5. Provenance & Scale Honesty

Every polygon contains explicit provenance. If evidence is insufficient, the system does not hallucinate. Scale states: METRIC_CALIBRATED, BLUEPRINT_CALIBRATED, USER_CALIBRATED, or RELATIVE_SCALE.
